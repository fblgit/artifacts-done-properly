ARTIFACT KIT CATALOG v2. Building blocks for claude.ai artifacts: components, themes, templates, guides.
You TAKE an entry's files BY REFERENCE. You do not copy code by hand.
This artifact's own URL is the catalog URL: https://claude.ai/artifact/LzGUCv8xCa8XLnqwF7Vemx

INSTALL THE ADP SKILL (once per machine, before ADP take / ADP check; skip if ~/.claude/skills/adp/SKILL.md exists):
  1. Download adp.skill from the latest release: https://github.com/fblgit/artifacts-done-properly/releases/latest (it is a zip whose root folder is adp/).
  2. Unzip it into your skills folder: unzip adp.skill -d ~/.claude/skills
  3. Run: python3 -I ~/.claude/skills/adp/scripts/adp.py setup --dry-run, then read ~/.claude/skills/adp/SKILL.md (First run): it says which scope to ask the user (user, project or local) and then runs setup with it.
  No pip or npm is needed; the script is Python 3 standard library only.

WHERE TO START
  1. Read catalog.json (id, name, summary, tags). Do not open every page.
  2. Pick the entry and everything it requires (listed first, in load order).
WHAT TO GET
  Put a files map in the files of your artifact's Artifact publish, one reference per file:
  {"kit/tabs.js": {"artifact": "<catalog url>", "path": "kit/tabs.js"}}
  The server copies the file. You must be able to open this artifact.
  Scripts, styles, data and images copy. HTML and XML pages do not: templates are .html.txt text,
  copy the shell into your own index.html. The Take it tab of each entry prints the exact map.
WHAT TO CHECK
  Read each taken file back from your artifact: its sha256 equals the one under Files.
  Required entries loaded first. The theme supplies the colour tokens, components carry no literal colour.
  No horizontal scroll at 390 px. Do not edit a taken file in place: fix it here and take it again.
HOW ADP WORKS (guide: entry guide.artifact-dataplane, file kit/guides/artifact-dataplane.md)
  adp/2 layout = thin index.html + adp.js + content.js + parts/ + styles/. Every piece is a part with a
  stable id, marked in the source and with data-part. Per-part hashes say what changed. Copy lives in
  content docs, with content.js as the fallback. Comment anchors are part ids. Several agents edit through
  read, hold, publish, record, with if_version pinned on every write. python3 -I adp.py check must say ok.
