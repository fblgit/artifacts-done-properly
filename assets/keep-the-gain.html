03 / Keep the gain

Build on your best version.

A growing catalog gives you more to start from. Refinement becomes an investment you can carry across pages and projects.

More to start from

A page built with ADP doesn't start from a blank file. The v2.0.0 base catalog has 139 entries: components, patterns, charts, layouts, themes, templates and guides. Each one is versioned and hashed file by file.

  • 53patterns
  • 30charts and visualisations
  • 27kit components
  • 13themes
  • 9layouts

Templates that stack

The three templates build on each other. starter is the shell, the runtime, a welcome view, settings and the What changed panel. assistant adds the Work with Claude pane, the Requests view and presence. default adds every theme, the canvas, 3D and the common kits, 82 catalog entries taken by reference.

  • starter
  • assistant
  • default

Find it before you rebuild it

Before building something by hand, ask the catalog:

adp.py suggest CATALOG --for "budget table with totals"

It ranks entries by how well they match on tags, name, summary and what they provide, and says why each matched. No model call is involved.

Refinement becomes an investment

When a component has been through rounds of refinement, that work doesn't have to stay in one page. Once it is in the catalog, the next page takes it by reference and starts from your best version, across pages and projects.

Not there yet in v2.0.0: the full template tier, and a command to add catalog entries. For now, an entry is added by editing files under catalog/kit/ and catalog.json by hand.
